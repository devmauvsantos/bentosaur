## Why this gate exists

Visual Gate 01 proved that Tripo could reconstruct the complete upright
Triceratops form. It did not produce final Bentosaur materials. The original
PBR board is overlit and washed out, the clay board intentionally disables
textures, and the toon board is a diagnostic shader.

The user accepted the P1 form as a strong 3D option but has not approved the
automatic surface as the final character.

## Material contract

- Sage body with controlled light, mid, and shadow values.
- Warm cream belly, horns, frill knobs, claws, and dorsal knobs.
- Coral cheek marks and tongue.
- Dark ink eyes and mouth line.
- Dark burgundy mouth cavity.
- Matte, soft toy-like roughness; no metallic response.
- Restrained surface variation; no uncontrolled Tripo normal-map noise.
- Separate, replaceable face controls rather than a permanently painted
  expression.

Target sampled ranges:

- Sage: `#728875`, `#657A68`, `#566A58`
- Cream: `#E9D0A5`, `#CFB78E`
- Coral: `#C98D66`
- Face ink: `#1B110C`

## Mouth construction contract

The P1 mouth is only a shallow geometric crease. It has no production cavity,
tongue, jaw, lip loops, or facial shapes.

The production mesh must add:

- relaxed closed or barely parted neutral rest state;
- concentric deformation-friendly lip loops;
- a real mouth bag/interior;
- a separate rounded tongue;
- no visible teeth unless a later design gate explicitly requests them;
- jaw-ready lower-muzzle topology;
- pre-rig facial shapes for closed smile, delighted open smile, cheek lift, lip
  seal, and chew support.

The open smile is an expression of the same master character. It is not a
second Tripo generation and not the neutral bind pose.

## Approval evidence

The user must receive:

1. neutral closed-mouth six-view board;
2. delighted open-mouth front and three-quarter renders;
3. side open/closed hinge comparison;
4. mouth-interior and tongue close-up;

## Evidence produced so far

### Lookdev Preview 0 — provisional, not final

The first corrected Blender render package now shows the P1 form and its
existing Tripo base-color information under controlled matte lighting. The
generated normal and ORM maps are disconnected, roughness is `0.79`, and the
raw source GLB remains unchanged.

It includes:

- a six-view neutral board;
- a neutral face close-up;
- 64 px and 96 px native-scale tests;
- a rainy-stall-like fixed-camera lighting proxy.

This is useful for judging the current form and proving that the sage, cream,
coral, and ink information exists. It is not final palette or material-zone
approval because it still uses the single autogenerated texture.

Local package:
`art/candidates/tripo/visual-gate-02/lookdev-preview-0/`

### Mouth construction prototype — geometry proof only

A disposable duplicate of P1 now contains an actual Boolean-carved mouth
cavity and a separate coral tongue. The raw GLB remains unchanged. This proves
that a volumetric toothless mouth can fit the accepted silhouette.

The result is not a visual approval candidate: its opening reads more like an
“O” than the canonical delighted smile, and its Boolean boundary and separate
rim are not deformation topology. The production pass still needs a broad
smile shape, connected mouth bag, concentric lip loops, jaw-ready topology,
shape keys, and closed/open/chewing deformation QA.

Local package:
`art/candidates/tripo/visual-gate-02/mouth-prototype/`

Neither evidence package unlocks rigging.

## Artifact audit — July 29, 2026

The user correctly identified three visible defects:

- **Eye ghosting/doubling:** present in the embedded Tripo base-color texture
  and in Tripo's raw preview before the Blender lookdev pass. P1 has no separate
  eye objects; the eyes are projected into one texture. Final eyes must be
  rebuilt as controlled geometry or decals with either authored catchlights or
  real specular response, never both.
- **Open-mouth rim and seam:** introduced by the disposable Blender Boolean and
  mouth-insert prototype. This is not a Tripo HD result and must not be treated
  as appearance evidence.
- **Lumpy cream frill knob / horn forms:** already present in P1 geometry and
  compounded by baked shading in the source texture. At roughly 5,000 triangles,
  small rounded features are under-resolved and pinched.

The previous P1 versus H3.1 comparison was optimization-first, not a true
hero-quality bakeoff:

- P1 used a `5,000` face limit and Standard texture quality.
- H3.1 used Standard geometry, Smart Low Poly, and the same `5,000` face limit.
- Neither run tested H3.1 Detailed / high-density hero geometry.

Therefore P1 should be retained only as a useful silhouette and proportion
reference. It is not an efficient source for direct production repair.

## Corrected proposed next test — pending user authorization

Run geometry before texture:

1. prepare flatter, more metrically consistent orthographic views with no baked
   catchlights or directional shadows;
2. generate H3.1 multiview with Detailed geometry, Smart Low Poly disabled,
   texture/PBR disabled, and no 5,000-face hero cap;
3. review untextured clay close-ups of the eyes, muzzle, horns, frill knobs,
   hands, feet, and tail;
4. choose a high-detail sculpt only if it materially improves the source;
5. retopologize the selected form and manually construct eyes, muzzle, mouth
   cavity, tongue, and deformation loops;
6. author semantic materials after the clay mesh passes.

The current official estimate recorded for this proposed geometry-only H3.1
Detailed multiview test is `40` Tripo credits per candidate. No API request was
made during this audit.
