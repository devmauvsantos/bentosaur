# Lilita One

`LilitaOne-Regular.ttf` is the unchanged official Google Fonts distribution
of Lilita One Regular. It is used for Bentosaur's live, localizable stall-menu
labels.

- Source: <https://github.com/google/fonts/tree/main/ofl/lilitaone>
- License: SIL Open Font License 1.1 (`OFL.txt`)
- Font SHA-256: `f5b641c45c69d772ee4eda687bc9fda411d5cad6b0b45371491da4580cbc8d59`

The font file, upstream metadata, and license text are vendored together.
